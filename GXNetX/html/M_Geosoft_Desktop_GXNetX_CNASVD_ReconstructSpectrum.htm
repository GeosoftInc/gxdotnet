Remarks
Performs spectral reconstruction using only the first N eigenvectors/components. This effectively filters the data by removing noise associated with higher-order components while preserving the signal in the dominant components. The reconstructed data is written to the specified output channel on all lines used to create the NASVD object originally (see NASVD::Create, for more details).
